# Ready-to-open previews

Built copies of the app. Download either file and double-click it — no install needed.

- `atco-marine-app.html` — the full app (desktop, tablet or phone browser).
- `atco-marine-phone-preview.html` — the same app inside an iPhone / Android frame, for viewing the phone layout on a computer.

Demo only: fictional data, no real payments or logins. Accounts are stored only in the browser that opens the file.
These files are snapshots — rebuild them after changing `src/`.
