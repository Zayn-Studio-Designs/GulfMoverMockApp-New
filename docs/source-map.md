2. **Client Requirements**: Directory 01 contains the original client brief, clarifications, compliance matrix, and requirement breakdown
3. **UX/UI Assets**: Directory 03 contains the bilingual HTML prototype (`gulf_mover_ui_prototype_bilingual.html`) along with wireframes, design system, and UX research
4. **Business Rules**: Directories 05-06 contain detailed specifications for features, business rules, integrations, and vendor evaluations
5. **Technical Architecture**: Directory 04 contains data model, access rules, hosting plans, and system architecture options
6. **Testing & Operations**: Directories 08 and 10 contain test plans, implementation plans, workflows, and support documentation
7. **Proposal Materials**: Directory 09 contains commercial and technical proposals plus TCO modeling
